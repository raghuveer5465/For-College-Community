HAVE QUESTIONS?

Frequently Asked Questions

Here are some simple answers about using Campus Share Hub.

Who can use Campus Share Hub?

Verified students and authorized members of the college community can use the platform.

How does the Lost & Found system work?

Report a lost or found item with its name, description, location, date, and photo. If you find a matching item, contact the reporter and verify the item’s unique details before returning it.

How does borrowing work?

Find an available item, send a request, agree on a return time, confirm the handover, and return the item on time.

What happens if an item is returned late?

The borrower should request an extension before the deadline. Repeated late returns may temporarily restrict borrowing access and can be reviewed by an administrator.

What should I do if I find someone’s item?

Report the item with its location and description so the owner can identify and safely recover it.
